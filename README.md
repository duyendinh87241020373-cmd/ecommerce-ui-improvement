
# E-commerce UI Improvement

## 1. Giới thiệu

Dự án cải tiến giao diện thẻ sản phẩm cho website
thương mại điện tử, tham khảo từ Shopee Việt Nam.

Mục tiêu:
- Hiển thị thông tin sản phẩm rõ ràng.
- Làm nổi bật giá bán và tỷ lệ giảm giá.
- Giúp khách hàng dễ so sánh giá.
- Thiết kế giao diện phù hợp với máy tính và điện thoại.

## 2. Website tham khảo

- Tên website: Shopee Việt Nam
- URL: https://shopee.vn
- Khu vực khảo sát:
  1. Trang chủ
  2. Danh mục sản phẩm
  3. Chi tiết sản phẩm
  4. Tìm kiếm
  5. Giỏ hàng

## 3. Chức năng

- Hiển thị danh sách gồm 4 sản phẩm mẫu.
- Hiển thị hình ảnh và tên sản phẩm.
- Hiển thị giá bán và giá gốc.
- Hiển thị phần trăm giảm giá.
- Có nút "Thêm vào giỏ" minh họa.
- Giao diện Responsive cho máy tính và điện thoại.

Lưu ý: Nút Thêm vào giỏ chỉ mang tính minh họa
giao diện, chưa xử lý dữ liệu giỏ hàng.

## 4. Công nghệ sử dụng

- HTML5
- CSS3
- Visual Studio Code

## 5. Cách chạy

1. Tải mã nguồn về máy.
2. Mở thư mục dự án.
3. Mở file index.html bằng trình duyệt Chrome.
4. Kiểm tra giao diện trên máy tính và điện thoại.

## 6. Cải tiến đã thực hiện

Thiết kế lại thẻ sản phẩm bằng HTML/CSS:
- Giá bán được làm nổi bật.
- Giá gốc có dấu gạch ngang.
- Nhãn phần trăm giảm giá dễ nhận biết.
- Nút thao tác được trình bày rõ ràng.
- Bố cục sản phẩm thay đổi theo kích thước màn hình.
